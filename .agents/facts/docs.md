# Documentation facts

- `docs/SPEC.md` is the authoritative product spec with stable requirement
  ids. Other documents defer to it.
- `docs/dev/specs/board-format.md` and `docs/dev/specs/agent-protocol.md` are
  the detailed contracts for files and agents.
- `README.md`: orientation, install, run, agent setup.
- `docs/dev/roadmap.md`: lean execution index; briefs in
  `docs/dev/roadmap-items/`; active ExecPlans in `docs/dev/plans/`
  (`NNN-short-title.md`, deleted after completion).
- `docs/dev/decisions.md`: durable decisions with options and rationale.
- `docs/dev/prompts/`: prompts for starting agent work (kickoff).
- `docs/dev/guides/`, `docs/dev/ops/`: contributor guides; release and
  security operations (`docs/dev/ops/release-governance.md`).
- `docs/user/`: user guides, created when there is behaviour to document.
- `CHANGELOG.md`: Keep a Changelog, curated, `Unreleased` first.
- Documents distinguish implemented from planned behaviour, and state agent
  version assumptions (hook schemas) with the date they were checked.
